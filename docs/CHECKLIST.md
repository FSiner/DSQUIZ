# 수업 전 점검표

## 배포 직후 (한 번만)
- [ ] 로컬 모드라면 비밀번호를 `1234` 에서 변경했다 (Firebase 연결 시에는 아이디·비밀번호 계정)
- [ ] Firebase 익명·이메일/비밀번호 로그인을 켰다
- [ ] 최신 규칙(classes 포함)을 게시했고, 선생님 계정을 만든 뒤 teachers 명단에 UID를 true 로 등록했다
- [ ] 폰에서 학생으로 접속해 퀴즈를 풀어 봤다
- [ ] 선생님 화면에 학생 응답이 실시간으로 보인다
- [ ] QR 버튼으로 나온 QR을 폰으로 찍어 열린다

## 학생 화면 점검 (아직 자동 검증을 못 한 항목)
- [ ] 학생 화면에 판서 켜기 버튼이 보이지 않는다
- [ ] 모든 문제를 풀면 결과 화면이 자동으로 나온다
- [ ] 틀린 문제만 다시 풀어도 선생님 화면 현황이 초기화되지 않는다
- [ ] 정리 노트 기능이 보이지 않는다

## 매 수업 전
- [ ] 교실 네트워크에서 앱 주소가 열린다
- [ ] 전자칠판/태블릿에서 펜·손가락 판서를 확인했다
- [ ] 퀴즈를 공개로 바꿨다 / 힌트 공개 여부를 정했다
- [ ] 퀴즈 JSON을 내보내기로 백업했다

## 반 기능 점검
- [ ] 선생님 로그인 후 [반 관리]에서 반을 만들었다
- [ ] 퀴즈의 [공개 설정]에서 반을 체크해 공개했다
- [ ] 다른 기기에서 학생으로 입장하면 반 버튼이 보이고, 체크한 반에서만 퀴즈가 보인다
- [ ] 선생님 결과 화면에 반별 탭이 보이고, 미응시 학생을 삭제할 수 있다
