# Firebase 연결 (DSQUIZ)

연결하지 않으면 데이터가 한 브라우저 안에만 저장되어 학생 기기와 공유되지 않습니다.
연결하면 **선생님은 아이디·비밀번호**, **학생은 익명 로그인(이름만 입력)** 으로 동작하고 보안 규칙이 서버에서 확인합니다.

## 1. 프로젝트와 Realtime Database
1. console.firebase.google.com → 프로젝트 추가 (애널리틱스는 꺼도 됨)
2. 빌드 → **Realtime Database** → 데이터베이스 만들기 → 잠금 모드로 시작

## 2. 로그인 켜기 (필수)
빌드 → **Authentication** → 시작하기 → **Sign-in method**
1. **익명** 사용 설정 → 저장
2. **이메일/비밀번호** 사용 설정 (아래쪽 "이메일 링크"는 끄고 저장)

## 3. 보안 규칙 (필수)
Realtime Database → **규칙** 탭 → `database.rules.json` 내용 전체를 붙여 넣고 **게시**.
수정할 곳은 없습니다. 선생님 여부는 규칙이 아니라 데이터의 `teachers` 명단이 정합니다.

- 퀴즈·힌트: 로그인한 누구나 읽기, 선생님만 쓰기
- 학생 목록·응답: 선생님만 읽기. 학생은 자기 uid로 만든 기록만 쓰기
- `teachers` 명단: 앱에서는 쓸 수 없고 **콘솔에서만** 수정 가능

## 4. 웹 앱 설정 값을 코드에 넣기
1. 프로젝트 설정 → 일반 → 내 앱 → 웹 앱(`</>`) 등록 → `firebaseConfig` 복사
2. `databaseURL` 이 없으면 Realtime Database 화면 위쪽 주소를 추가
3. `index.html` 의 `const FIREBASE_CONFIG = null;` 을 복사한 객체로 바꾸고 GitHub에 올립니다.

## 5. 선생님 계정 추가 (선생님마다 반복)
선생님께 받은 아이디가 `kim`, 비밀번호가 `비번` 이라면:

1. **Authentication → Users → 사용자 추가**
   - 이메일: `kim@dsquiz.app` (아이디 뒤에 `@dsquiz.app` 을 붙임. 실제 메일이 아님)
   - 비밀번호: 받은 비밀번호 (6자 이상 필수)
   - 추가한 뒤 목록에서 그 계정의 **사용자 UID** 를 복사합니다.
2. **Realtime Database → 데이터** 탭에서 `smartquiz` 아래에 `teachers` 를 만들고 그 아래에 UID 를 키로, 값을 `true` 로 넣습니다.
   - 예: `smartquiz` → `teachers` → `복사한UID` : `true`
   - 값은 따옴표 없는 `true`(불리언)여야 합니다. 글자 "true"로 넣으면 인정되지 않습니다.
3. 앱에서 아이디 `kim` 과 비밀번호로 로그인되는지 확인합니다.

## 선생님 삭제·비밀번호 변경
- 삭제: `teachers` 의 해당 UID 항목을 지우고, Authentication 에서 계정도 삭제
- 비밀번호 변경·분실: Authentication → Users → 해당 계정 → 비밀번호 재설정(재설정 메일은 가짜 주소라 받을 수 없으므로, 계정을 지우고 새로 만든 뒤 새 UID 로 `teachers` 를 갱신하세요)

## 아이디 규칙
영문·숫자와 `.` `_` `-` 만, 2~30자. 대소문자는 구분하지 않습니다.

## 알아둘 점
- 학생이 개발자 도구로 계정을 만들 수는 있지만, `teachers` 명단에 없으면 아무 권한이 없습니다.
- 학생은 퀴즈 데이터를 읽을 수 있어서 **정답이 든 내용을 개발자 도구로 볼 수 있습니다.** 시험용에는 맞지 않습니다.
- 같은 이름을 **다른 기기**에서 쓰면 두 번째 기기의 기록은 거부됩니다. 이름을 바꿔 입장하세요.
- 선생님 기기에서 학생 화면을 확인할 때는 시크릿 창이나 다른 기기를 쓰세요.
- 선생님이 만든 퀴즈는 그 브라우저에 저장됩니다. 다른 기기에서 쓰려면 JSON 내보내기·불러오기를 쓰세요.

## 문제 해결
| 증상 | 확인할 것 |
|---|---|
| "이메일/비밀번호 로그인이 꺼져 있습니다" | 2단계 |
| "아이디 또는 비밀번호가 맞지 않습니다" | 콘솔 이메일이 `아이디@dsquiz.app` 인지, 비밀번호 오타 |
| "선생님으로 등록되지 않은 계정입니다" | 5단계 2번. UID 오타, 값이 불리언 `true` 인지, `smartquiz` 아래에 만들었는지 |
| 퀴즈 공개·응답 저장이 거부됨 | 규칙 게시 여부, 익명 로그인 켜짐 여부 |
| 학교에서만 안 됨 | `firebaseio.com`, `firebasedatabase.app`, `gstatic.com`, `googleapis.com` 차단 여부 |
